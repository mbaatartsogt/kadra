# Сүхбаатарын талбайн тулаан 3D — сервер

Express + Socket.IO сервер. `public/index.html` бол тоглоом өөрөө.
Сервер нь тоглогчдын байрлал, буудлага (hit/kill), раундын цаг, Кадраг хэн түрүүлж алсныг зохицуулна.

## Компьютер дээрээ турших
```
npm install
npm start
```
Дараа нь хөтчөөр http://localhost:3000 нээнэ. Хоёр таб нээвэл хоёр тоглогч болно.

## Render дээр байрлуулах
1. GitHub дээр шинэ repository үүсгээд энэ хавтасны бүх файлыг оруулна (`node_modules`-ээс бусад).
2. https://render.com → **New → Web Service** → GitHub repo-гоо холбоно.
3. Тохиргоо:
   - Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: **Free**
4. **Deploy** дарна. Дуусахад `https://<нэр>.onrender.com` хаяг гарна — тэр холбоосыг найзууддаа явуулна.

## Анхаарах
- Үнэгүй сервер 15 минут хэн ч ороогүй бол унтдаг. Дараагийн хүн ороход 30–60 секунд хүлээнэ.
- Оноо серверийн санах ойд хадгалагддаг тул сервер унтах/дахин эхлэхэд оноо тэглэгдэнэ.
